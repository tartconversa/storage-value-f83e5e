# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

半小时时段。power_kw 为平均功率，实际充电为正、放电为负；command_kw 是指令不能替代缺失的 actual_kw。soc_kwh 是时段起点，缺测为空。forecast_issue 必须不晚于目标时段，issued_at 表示当时预报。battery 的效率在0到1之间；capacity_kwh 随累计放电衰减，degradation_kwh_per_mwh 是容量减少量。月需量以月内共享变压器总功率最大值计，不是日电量。charge 禁止突破变压器余量，reserve 为连续供电义务，priority_notice 生效后替换对应义务。policy 仅为候选规则描述，不能把其中的规则输入当历史动作概率。
operations.start 是唯一目标时刻，forecast.available_at 若早于 issued_at，以二者较晚时刻为可用；后续资料修订不隐含早知。原始运行可能违反之后发布的保供要求，这属于待分析事实，不代表历史数据错误。策略按价格阈值提出动作且受功率和 forecast_peak_kw 条件影响，保供是硬约束；条件冲突时应说明如何形成可执行策略及其价值范围。没有记录动作选择概率，不能编造已知概率，须明确支持与可识别限制。

## battery
物理与衰减契约。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| battery_id | string | 电池 |
| capacity_kwh | number | 初始容量 |
| min_soc_kwh | number | 电量下限 |
| max_power_kw | number | 功率上限 |
| charge_eff | number | 充电效率 |
| discharge_eff | number | 放电效率 |
| degradation_kwh_per_mwh | number | 每兆瓦时容量衰减 |
| initial_soc_kwh | number | 最初电量 |

记录键：battery_id。

## operations
历史运行与实际计量有缺口。电池未提供全程电量真值。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| period_id | string | 时段 |
| start | datetime | 开始 |
| other_load_kw | number | 其他负荷 |
| price | number | 电价 |
| command_kw | number | 指令 |
| actual_kw | number | 实际 |
| execution | string | 执行状态 |
| meter_scope | string | joint或separate |
| transformer_kw | number | 总表 |
| available_at | datetime | 可知 |

记录键：period_id。

## forecasts
每个目标时段保留发布时刻，生成情景只依照可知信息。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| forecast_id | string | 预报 |
| target | datetime | 目标时刻 |
| issued_at | datetime | 发布时间 |
| load_kw | number | 负荷预报 |
| price | number | 电价预报 |
| available_at | datetime | 可知 |

记录键：forecast_id。

## state_observations
有限实际电量校核，不预写完整轨迹。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| state_id | string | 观测 |
| period_id | string | 时段 |
| soc_kwh | number | 起始电量 |
| error_kwh | number | 绝对误差 |
| available_at | datetime | 可知 |

记录键：state_id。

## tariffs
月度需量计费与变压器约束。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| month | string | 月份 |
| demand_yuan_kw | number | 每千瓦月费 |
| transformer_limit_kw | number | 容量 |
| already_peak_kw | number | 评审时已发生峰值 |

记录键：month。

## reserve
保供开始时需要可连续供应的功率与时长。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reserve_id | string | 义务 |
| start | datetime | 开始 |
| end | datetime | 结束 |
| required_kw | number | 保供功率 |
| duration_h | number | 连续小时 |
| known_at | datetime | 可知 |

记录键：reserve_id。

## priority_notice
新增保供义务不改变过去已执行行动。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| notice_id | string | 通知 |
| reserve_id | string | 被替换义务 |
| required_kw | number | 新功率 |
| duration_h | number | 新小时 |
| effective_at | datetime | 生效 |
| known_at | datetime | 可知 |

记录键：notice_id。

## policies
用户选择的规则条件，所有条件只可使用当时可知量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| policy_id | string | 候选 |
| charge_below_price | number | 低价充电阈值 |
| discharge_above_price | number | 高价放电阈值 |
| forecast_peak_kw | number | 预报削峰触发 |
| reserve_margin_kwh | number | 额外保供余量 |

记录键：policy_id。
